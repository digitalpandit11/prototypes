RADICAL CAREERAI — INTERACTIVE DEMO
====================================

HOW TO OPEN
  1. Keep this whole folder together (do not move index.html on its own).
  2. Double-click  index.html  (Google Chrome or Microsoft Edge recommended).
  3. Sign-in details are already filled in. Press "Sign in".
     - Student tab  -> Aarav Sharma (Radical student)
     - Admin tab    -> Sneha Kulkarni (Radical placement admin)
  4. Click the red "Demo guide" button in the black bar at the top for a guided tour of every screen.

TIPS
  - The black bar lets you switch between Student and Admin at any time and switch the student's
    interview plan between Basic and Premium.
  - "Voice on" makes the AI participants speak using your computer's built-in voices
    (works best in Chrome / Edge). Switch it off if you prefer silent subtitles.
  - "Reset demo" restores the original sample data.
  - Everything is sample data. Nothing is sent anywhere; the demo works offline.

FOLDER CONTENTS
  index.html        the application
  external.html     a simulated employer site (opens when you press "Apply now")
  assets/           styles, scripts, fonts and the Radical Technologies logo
